📚 Training Manual

Makhanani LTSM — How To Use The System — For Librarian, Teacher, HOD, Principal, Super Admin

📚 Lending Page →🏫 School Login →

1. Login

  • Open index.html or school.html
  • Wordsworth: EMIS 700310854 or Code WHS + Password Wordsworth2026
  • George Sonto: EMIS 911360870 or Code GSHS + Password GeorgeSonto2026
  • Each EMIS sees ONLY its own data. Never mixed.

2. Issue A Book (Librarian / Teacher)

  1. Go to Issue Books tab
  2. STEP 1: Scan / Type Book Barcode e.g. BK-MAT10-001 → Enter → Click Find Book
  3. STEP 2: Scan / Type Learner ID e.g. WHS-0001 → Enter → Click Find Learner
  4. STEP 3: Click ISSUE BOOK NOW
  5. Due Date is always 30 November

3. Return A Book

  • Go to Return Books tab
  • Option A: Scan Book Barcode → Return This Book
  • Option B: Search Learner → Tap Book → Return

4. HOD — Approve Requests

  • Open hod.html → Select Your Name + Dept
  • See Teacher Requests → Approve or Decline
  • See Overdue In My Dept → Follow up

5. Teacher — Issue + Request

  • Open teacher.html → Select Your Name
  • Issue Book To Learner → Select Book + Learner + Class
  • Request Books → Type book needed → Send to HOD

6. Dashboard — Principal / Super Admin

  • Open dashboard.html → See Total Stock, Available, Issued, Returned, Overdue, % Retrieval
  • Formula: Returned ÷ Total Ever Issued × 100
  • Print Summary → Print Overdue List for HODs

7. Upload (DBE Schools)

  • Open upload.html → Confirm EMIS → Download Template → Fill in Excel → Save As CSV → Upload
  • Never upload another school's data.

8. Common Problems

  • Book not found: Check barcode, check EMIS — you may be in wrong school
  • Learner not found: Check Learner ID, add learner in Learners tab
  • Logo not showing: Check logo.png is in GitHub root, hard refresh Ctrl+Shift+R
  • Books not correlating: Hard refresh — Sync Bridge merges WHS/GSH ↔ EMIS on every load
