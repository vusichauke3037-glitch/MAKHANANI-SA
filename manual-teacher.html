1. What Teacher Can Do

Teacher can Request books, View books for their subjects, Track their requests. Teacher cannot Add / Delete books or Issue / Return — Librarian does that.

2. Login

Home → Login → Email + Password → Teacher Dashboard.
Check top: Your School + EMIS + Your Subjects + Your Classes. If Subjects / Classes are wrong, tell Super Admin to fix your account.

3. Request Books — Step By Step

1. Teacher Dashboard → Request Books → Select Subject e.g. Mathematics
2. Type Book Title e.g. Mathematics Grade 10
3. Type Grade e.g. 10, Qty e.g. 30, Note e.g. For 10A, 30 learners
4. Tap Send Request → Status: Pending
5. Wait for HOD / Principal / Librarian to Approve. Approved = Librarian will issue books to your class.
6. If Rejected, check note / ask HOD why, then re-request with correct title / qty.

4. Check My Requests

Dashboard → My Requests → Shows: Title, Subject, Grade, Qty, Status: Pending / Approved / Rejected, Date.
Pending = Waiting. Approved = Ready. Rejected = Fix and re-send.

5. View Books For My Subjects

Dashboard → Books — My Subjects → Shows only books for your subjects.
Example: If you teach Mathematics, you see only Mathematics books, not English books.
Available = In library, can be issued. Out = With learners.

6. Book Number & Learner ID

When Librarian gives you books, each book has a label: WHS000001 (Wordsworth) or GSHS000001 (George Sonto).
Each learner has ID: 10A001 (Grade 10, Class 10A, Number 001).
If a learner loses a book, tell Librarian the Book Number WHS000001 — Librarian can find who had it.

Teacher Tip: Request early — 1 week before you need books. Do not wait until day of lesson. Always include Grade + Class + Qty in Note.
