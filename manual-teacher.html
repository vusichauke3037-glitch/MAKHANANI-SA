👩‍🏫 Teacher Manual

Makhanani LTSM • Xintimani Group

Your Job: Request for YOUR class, Issue to YOUR learners, Retrieve when done.

1. Login

Go to login.html → Email + Password → Top must say TEACHER. Set MY CLASS = Your Class, e.g. 10A. You can ONLY work in your class.

2. Request

Tab 📝 REQUEST → Pick Book → Class = Your Class → Qty → SEND REQUEST TO HOD. Wait for HOD.

3. Check Status

PENDING = Waiting HOD. APPROVED = Librarian can pack. REJECTED = Read reason, request again with less qty.

4. Issue

Tab 📤 ISSUE → Pick PACKED book OR Scan Barcode WHS000001 → Pick Learner in SAME class → ISSUE BOOK.
Blocked if: Book NOT PACKED, Packed for different class, Book Grade ≠ Learner Grade, Learner already has same Title. 1 Learner = 1 Title.

5. Retrieve

Tab 🔁 RETRIEVE → Scan / Pick ISSUED book → RETRIEVE. ANY teacher can retrieve ANY book. Do this at end of term / when learner leaves.

6. Records + Loan Form

Tab 📋 RECORDS → Search learner name to see what they have. Tab 📄 LOAN FORM → Print → Learner signs when taking book, signs again when returning.
