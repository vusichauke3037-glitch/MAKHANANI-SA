Your Job: Approve or Reject requests for YOUR Department only.

1. Login + Set Department

Go to login.html → Top must say HOD. Set MY DEPT = Your Department, e.g. Mathematics. You see ONLY your Department.

2. Approve

Tab ✅ HOD → See request → Change Approved Qty if needed (cannot be more than Requested) → ✅ APPROVE. Example: Teacher asks 30, you have 25 → Set 25 → Approve.

3. Reject

❌ REJECT → Type reason, e.g. Not enough books. Teacher will see reason.

⛔ Rule

If you don't approve, Librarian CANNOT pack. If you approve wrong qty, Librarian can only pack that qty. Check 📦 PACKAGE to see if Librarian packed it.
