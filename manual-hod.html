1. What HOD Can Do

HOD can Approve / Reject requests for THEIR subjects, View stock for their subjects, View Issue / Return. HOD cannot Add / Delete books.

2. Login

Home → Login → Email + Password → HOD Dashboard.
Check top: Your Subjects. If you are HOD for Mathematics, you see only Mathematics requests / books. If Subjects = General, you see all.

3. Approve / Reject Requests

1. HOD Dashboard → Requests — My Subjects
2. Check: Is Title correct? Is Qty reasonable? Is Grade correct?
3. Tap ✅ Approve if correct → Teacher + Librarian see Approved.
4. Tap ❌ Reject if wrong title / too many / wrong grade → Teacher must re-request.
Approve quickly — Teachers wait for books.

4. Stock — My Subjects

Dashboard → Stock — My Subjects → Shows: Title, Subject, Grade, Copies, Available, Book Numbers e.g. WHS000001.
Use this to check if you have enough books for your department before approving requests.

5. Issue / Return — View

Dashboard → Issue / Return — View → Shows recent issues: Book WHS000001, Learner 10A001, Issued / Returned, Date.
If many books are Out and not returned, tell Librarian to follow up.

6. Book & Learner Format

Book: WHS000001 (WHS + 000001, No Dash) • George Sonto: GSHS000001
Learner: 10A001 (Grade + Class + 001, No Dash)

HOD Rule: Only approve requests for your subjects. Do not approve requests for other departments — leave for that HOD / Principal.
