🛠️ Fix / Help — Common Problems

1. User says Guest
Go to 👥 USERS → Find user → EDIT → Set Role = LIBRARIAN / TEACHER / HOD / PRINCIPAL (NOT Guest) → Save → Tell user: Logout → Login → Ctrl+Shift+R
2. User sees wrong school
Go to 👥 USERS → EDIT → Fix EMIS → Save → User Logout → Login again.
3. Librarian cannot pack
Check: HOD approved? If PENDING, HOD must approve. If APPROVED but no books, check Stock → AVAILABLE qty. If 0, add stock.
4. Teacher cannot issue
Check: Book is PACKED? Packed for same class? Grade matches learner? Learner already has same title? If yes to last, blocked correctly.
5. School says EXPIRED
Go to 💳 SUBSCRIPTIONS → Find EMIS → EDIT → Status = ACTIVE → Set new Expiry Date → Save.
6. Forgot Password
Tell user: Login page → Forgot Password → Type email → Check inbox + spam.
7. Delete School
⚠️ Never delete a school with ISSUED books. Retrieve all books first in Librarian Dashboard → Then delete school + subscription + users.
