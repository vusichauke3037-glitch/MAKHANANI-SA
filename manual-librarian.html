📚 Librarian Manual

Makhanani LTSM • Xintimani Group • Joy. Cherished. Mercy.

Your Job: Stock is correct, Pack correctly, Print labels, Retrieve books.

1. Login

Go to login.html → Email + Password → You must see LIBRARIAN at top. If you see Guest → Logout → Login again → Tell Super Admin to fix your Role.

2. Set School + Class

Top bar → SCHOOL EMIS = Your School. MY CLASS = All Classes.

3. Departments First

Tab 🏛️ DEPARTMENTS → Add Mathematics, English, Afrikaans, Physical Sciences, Life Sciences, Social Sciences, Technology, EMS, Life Orientation + HOD Name. No Department = Cannot Add Book.

4. Add Stock

Tab 📦 STOCK → Title, Author, Grade, Department, Qty, Prefix WHS, Start No 1 → ADD BOOK(S). Example: Qty 30 = WHS000001 to WHS000030.

5. Edit Qty Per Title

Blue box Stock Per Title → Change NEW TOTAL QTY → SAVE QTY. Up = Adds new barcodes. Down = Deletes ONLY AVAILABLE copies. PACKED / ISSUED are protected.

6. Renumber

Tick books → Set START NO + PREFIX → RENUMBER SELECTED. Or RENUMBER ALL to close gaps. Then REPRINT labels.

7. Pack (Librarian Only)

Tab 📦 PACKAGE → Only APPROVED requests show → Qty ≤ Approved Qty → PACK. AVAILABLE → PACKED. Never pack more than HOD approved. Never pack if HOD has not approved.

8. Retrieve

Tab 🔁 RETRIEVE → Scan / Pick ISSUED book → RETRIEVE → Book becomes AVAILABLE.

9. Print Labels

Tab 🖨️ PRINT → Tick books → PRINT TICKED BOOKS. For learners → PRINT ALL LEARNERS. Labels are 3x5 on A4.

10. Add Learner

Tab 👧🏾 LEARNERS → Name + Class + Grade → ADD. ID auto = 10A001.

⛔ Never Do

Never issue a book that is NOT PACKED. Never delete a PACKED / ISSUED book. Use RESTORE to make it AVAILABLE.
