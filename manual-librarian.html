1. Login

1. Open Home → Tap Login.
2. Type Email + Password given by Super Admin.
3. You go to Librarian Dashboard for YOUR school only (EMIS).
Wordsworth: EMIS 700310854 • Prefix WHS • Book WHS000001
George Sonto: EMIS 911360870 • Prefix GSHS • Book GSHS000001

2. Book Number — WHS000001 — Do NOT Type It

Book Number = First Letter of Each Word of School Name + 6 Digits, No Dash.
Wordsworth High School = WHS + 000001 = WHS000001
George Sonto High School = GSHS + 000001 = GSHS000001
System auto-generates it. No duplicate. No skip. If you delete WHS000003, next book gets WHS000003 again.

3. Add Book — Step By Step

1. Librarian → Tab Books → Type Title e.g. Mathematics Grade 10
2. Author, ISBN (optional), Subject, Department, Grade, Copies e.g. 10
3. Tap Add Book → System shows: Book Numbers: WHS000001, WHS000002...
4. To add more copies of same title: Type same Title + Subject + Grade, Copies = 5 → System adds WHS000011 to WHS000015, does NOT create duplicate title.

4. Learner ID — 10A001 — Do NOT Type It

Learner ID = Grade + Class + 3 Digits, No Dash.
Grade 10, Class 10A = 10A001
Grade 10, Class A = 10A001 (same)
Grade 8, Class 8C = 8C001
System auto-generates per Grade + Class group. No duplicate. No skip. Delete 10A001 → Next learner in 10A gets 10A001 again.

5. Add Learner

1. Tab Learners → Type Full Name, Grade, Class e.g. 10, 10A
2. Preview shows Next Learner ID: 10A001
3. Tap Add Learner → Learner gets 10A001.
Next learner in same class gets 10A002. First learner in 10B gets 10B001.

6. Departments / Subjects

1. Tab Departments / Subjects → Add Department e.g. Languages → Add Subject e.g. English HL → Link to Languages.
2. New Department / Subject appears instantly in Add Book dropdowns.
Premium = Unlimited Departments / Subjects.

7. Issue Book

1. Tap Issue / Return → Type Book Number e.g. WHS000001 (scan or type)
2. Type Learner ID e.g. 10A001 → System shows Learner Name
3. Tap Issue Book → Book status becomes Issued.
If book already Issued, system blocks: Return it first.

8. Return Book

1. Issue / Return → Return → Type Book Number e.g. WHS000001 → Tap Return Book
2. Book becomes Available again.

9. Print Barcodes

1. Tap Print Barcodes → Tick copies to print → Tap Print Selected
2. Each label shows: Logo + School + Book Number WHS000001 + Title + Subject + Grade.
3. Stick label on book cover.

10. Stock

Tap Stock → Search by Title / WHS000001 / Subject / Grade → Filter Available / Issued.
Print Stock List for Principal / SGB.

11. Requests — Approve / Reject

Teachers send requests. Librarian Tab Requests → Tap ✅ Approve or ❌ Reject.
Approved = Ready to Issue.

12. If School Locks 🔒

If you see 🔒 School Locked, you cannot Add / Issue. Tell Principal / Super Admin to Pay / Renew in Finance. Super Admin can still view / fix.

Quick Rules:
• Never type Book Number or Learner ID — System generates them.
• Never use same Book Number for 2 books, same Learner ID for 2 learners in same class.
• Always check EMIS at top — Wordsworth 700310854 vs George Sonto 911360870 — Never mix schools.
• Export data after adding many books (Super Admin → Export).
