🎬 How Makhanani
Works — In 6
Cartoons!

Tap a cartoon to see what happens.

👩🏾‍🏫📝
1. Teacher Requests

Teacher: "I need 30 Maths books for 10A!"
Only for OWN class. HOD must approve.

✅ Rule: No Request = No Pack
👩🏾✅
2. HOD Approves

HOD sees ONLY own Department.
Sets Approved Qty. Example: Request 30, Approve 28.

✅ Rule: No HOD = No Pack
👩🏾‍💼📦
3. Librarian Packs

Librarian packs from AVAILABLE only, up to Approved Qty.
Packed books = Reserved, not AVAILABLE.

✅ Rule: No Pack = No Issue
📤👦🏾
4. Teacher Issues

Scan PACKED barcode → Pick Learner in SAME class → Issue.
1 Learner = 1 Title. Same learner cannot get same title twice.

📱 1 Scan = Issued!
🔁📚
5. Retrieve

ANY Teacher can retrieve ANY book.
Book becomes AVAILABLE again. Retrieval % goes up!

📊 Retrieval % = Retrieved ÷ Issued × 100
🖨️🏷️
6. Print

Print 3×5 labels: Book + Learner.
Loan Form signed by Learner + Parent.

🖨️ Print → Stick → Sign
