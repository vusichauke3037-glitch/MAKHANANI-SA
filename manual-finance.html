3. Setup Fee — Once-Off Forever

Setup Fee is paid ONCE, NEVER AGAIN. After first payment, tap 🏗️ Setup Paid in Finance. On renewal, Setup Due = R0.
If you do NOT mark Setup Paid, system will charge Setup again on renewal — wrong. Always mark Setup Paid after first payment.

4. Yearly = Start + 12 Months = End

Example: Start 2026-11-25 → End 2027-11-25. End is auto-calculated, cannot be extended.
After End, school locks automatically. Renew by setting new Start = Old End, new End = New Start + 12 Months.

5. Add / Update Subscription

1. Finance → Subscriptions → Select School (EMIS) → Select Package → Select Billing: Yearly
2. Setup Fee auto-fills (Premium R5,500) → Setup Paid: PAID / UNPAID
3. Amount auto-fills (Yearly R9,000) → Pick Start Date → End auto = Start + 12 Months
4. Status: Paid / Unpaid / Trial / Expired / Cancelled
5. Tap Add / Update Subscription (By EMIS)
EMIS must be unique — If EMIS already exists, tap ✏️ Edit on that card, do NOT create duplicate.

6. Calculate Total Due Now

Tap 🧮 Calculate Total Due Now → Shows: Setup Due (R0 if already Paid, else R5,500) + Subscription R9,000 = Total Due Now.
Example: Setup already Paid → Total Due Now = R9,000 only. Setup Unpaid → Total Due Now = R14,500.

7. Lock / Unlock

Paid / Trial = ✅ UNLOCKED — Users can Add / Issue
Unpaid / Expired / Cancelled / No Sub = 🔒 LOCKED — Users see 🔒 School Locked, cannot Add / Issue
Super Admin bypasses lock for fixing.
