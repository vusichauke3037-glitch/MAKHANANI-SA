👑 Super Admin Manual

Makhanani LTSM • Xintimani Group • Owner Only

Your Job: Create schools, activate subscriptions, fix users. Never share this login.

1. Create School

Super Admin → Add School → Name + EMIS + Principal Name + Plan. EMIS must be correct - all books / learners are linked to EMIS.

2. Activate Subscription

Find School → Set Plan: DEMO (FREE) / BASIC / PREMIUM / DONATION → Set Expiry Date → Save. If DONATION, set Donor Name, School Pays R0 for 12 months.

3. Create User

Add User → Name, Email, Role (LIBRARIAN / TEACHER / HOD / PRINCIPAL), EMIS, Department, Class. Tell them their password. Tell them to use login.html.

4. Fix User Says Guest

Check Users list → Role must NOT be Guest. If wrong EMIS, edit EMIS. Tell user: Logout → Login again → Hard Refresh Ctrl+Shift+R.

5. Fix Book / Data

Go to Librarian Dashboard → STOCK → Edit / Restore / Delete. Never delete a school with books still ISSUED. Retrieve first.

⛔ Security

Never give Super Admin to a school. Each school gets Principal only. Change your password if you share your screen.
