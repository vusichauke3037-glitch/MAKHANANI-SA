4. Finance — Set BOTH To Premium Yearly

1. Finance Dashboard → Pick Start Date (e.g. Today)
2. Tap 👑 Set BOTH To Premium Yearly → Both schools set: Premium, Yearly, Start → Start + 12 Months = End, Amount R9,000, Setup R5,500, Status Paid.
3. Total: R29,000 first 12 months. Renewal: R18,000 next 12 months.
4. If Setup already Paid, tap 🏗️ Setup Paid on that school card — Setup becomes R0 for renewal.

5. Lock / Unlock School

Finance → Lock Status → Tap ✅ Unlock (Paid) or 🔒 Lock (Unpaid) or 🏗️ Setup Paid per school.
Locked school: Users cannot Add / Issue, they see 🔒 School Locked full-screen. Super Admin can still view / fix.
Expired = End date passed → Locks automatically. Unpaid = Status Unpaid → Locks.

6. Export / Import — MUST DO

After ANY change (books, learners, subscriptions, setup paid): Super Admin → Export All Data → Save .json file.
On phone / other device: Super Admin → Import Data → Pick .json file → Data appears.
Export includes subscriptions + setup paid + both schools books / learners. If you do NOT Export, data stays on that device only.
