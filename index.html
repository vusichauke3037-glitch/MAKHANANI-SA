❓ How Book Numbers Work

Format: Prefix + 6 digits — Prefix = First letter of each word in school name.

  • Wordsworth High School → WHS + 000001 = WHS000001
  • George Sonto High School → GSHS + 000001 = GSHS000001
  • Accounting: G10 Learners WHS000001-70 • G10 Workbook WHS000071 (Qty 1) • G11 Learners 72-131 • G11 Workbook WHS000132 (Qty 1) • G12 Learners 133-212 • G12 Workbook WHS000213 (Qty 1)
  • Workbook Qty is always 1. Learners get the rest. No duplicates, no skipping.
  • Assign Numbers: In Librarian Dashboard → Yellow panel → Choose START for each already-added book → Preview → Apply.
