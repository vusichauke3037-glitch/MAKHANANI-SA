How To Use Book

Workflow: Teacher Requests → HOD Approves → Librarian Packs → Teacher Issues → Learner Uses → Teacher Retrieves

⚙️ How It Works — In 6 Steps

1. 📝 Teacher Requests
Teacher picks book + class + qty → Sends to HOD. Only for own class.
2. ✅ HOD Approves
HOD sees only own Dept → Sets Approved Qty → Approve / Reject with reason.
3. 📦 Librarian Packs
Librarian packs from AVAILABLE only, up to Approved Qty. AVAILABLE → PACKED.
4. 📤 Teacher Issues
Scan PACKED barcode → Pick learner in same class → Issue. 1 Learner = 1 Title. Grade must match.
5. 🔁 Teacher Retrieves
Any teacher can retrieve any book → Book becomes AVAILABLE again. Do at end of term.
6. 🖨️ Librarian Prints
Print Book Labels WHS000001 + Learner Labels 10A001. 3x5 on A4. Print Loan Form for signing.

⛔ Important Rules

  • ⛔ No HOD Approval = No Pack.
  • ⛔ No Pack = No Issue.
  • ⛔ Wrong Class / Wrong Grade / Already Has Title = Blocked.
  • ✅ Any Teacher Can Retrieve Any Book.
  • ✅ Librarian Can Restore Any Book To AVAILABLE.
  • 📄 Learner must sign Loan Form when taking + when returning book.
