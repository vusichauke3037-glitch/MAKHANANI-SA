📚 How It Works — 6 Steps

No HOD = No Pack. No Pack = No Issue.

1. 📝 Teacher Requests

Teacher picks book + class + qty. Only for OWN class.

2. ✅ HOD Approves

HOD sees ONLY own Department. Sets Approved Qty.

3. 📦 Librarian Packs

Packs from AVAILABLE only, up to Approved Qty.

4. 📤 Teacher Issues

Scan PACKED barcode → Pick Learner in SAME class → Issue. 1 Learner = 1 Title.

5. 🔁 Retrieve

ANY Teacher can retrieve ANY book. Book becomes AVAILABLE again.

6. 🖨️ Print

Print 3×5 labels: Book + Learner. Loan Form signed.
