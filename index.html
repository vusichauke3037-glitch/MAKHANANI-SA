📋 How It Works

  1. Teacher requests books → HOD approves Qty (e.g. 25) → Teacher can Issue max 25.
  2. Librarian adds Books + Learners (Parent Phone + Learner Phone Optional).
  3. Issue: Book Grade must = Learner Grade. Class 10A = Grade 10. No Grade Mismatch.
  4. Due: All books due 30 November every year. Warning from 23 Nov (7 days).
  5. Reminder: WhatsApp to Parent + Learner (if learner phone saved) + Copy SMS.
  6. Retrieval %: Returned ÷ Issued × 100 — Overall + Per Class / Dept / Teacher / Learner. Receipts stay clean (no % on receipt).
