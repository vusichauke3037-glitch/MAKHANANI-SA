2. Hiring Process — 7 Steps

  1. Application via WhatsApp / Email → Save in Super Admin → Leads → Career
  2. Phone interview (10 min): Why Xintimani? What can you do? When can you start?
  3. In-person / Video interview: Show ID, check references (1 school / employer)
  4. 7-Day Trial: Paid, specific tasks, daily check-in
  5. Decide: Pass = Offer letter, Fail = Thank you, pay trial, end
  6. Offer Letter: Role, duties, pay, hours, start date, probation 3 months, signed by both directors + staff
  7. Onboard: Give User Manual + Training Manual, add to Super Admin → HR

3. Staff Rules

  • Be on time, dress clean, speak respectfully to principals, teachers, learners
  • Never take money from schools without receipt + recording in Super Admin
  • Never share passwords, learner data, or school data outside school
  • Report problems same day to director, never hide
  • No phone scrolling during training / school visits

4. Pay Rules

  • Pay on agreed date, with payslip / receipt, record in Super Admin → HR + Finance
  • No pay without work logged. Trial pay = agreed amount, paid end of trial
  • Leave: Request 7 days before, director approves. Sick: Send message same morning + doctor note if 2+ days

5. Discipline

Verbal warning (1st) → Written warning (2nd) → Final warning / Suspension (3rd) → Dismissal. All warnings in writing, signed, filed.

6. Offboarding

Return all company property (phone, laptop, keys, documents), remove access (passwords changed), final pay after return, signed clearance.
