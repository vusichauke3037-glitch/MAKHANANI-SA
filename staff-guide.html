📁 2. THE 5 FILES — WHAT EACH FILE DOES

✅ 3. DAILY WORKFLOW — IN ORDER
Morning — Librarian: Open librarian.html → Add any new stock
Class — Teacher: Open teacher.html → Save Details (once) → Issue books one by one
End of Term — Teacher: Collect books → Return each WHS No in teacher.html
Weekly — HOD: Open hod.html → Check % Retrieval for your dept → Follow up on Still Out
SMT Meeting — Principal: Open dashboard.html → Principal → Print Summary → Sign
Filing — Librarian: Open record.html → Print → One page per class → File per class
