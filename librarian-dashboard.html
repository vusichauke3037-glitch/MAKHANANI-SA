📝 Requests

📌 Workflow: 1. Teacher Requests → 2. HOD Approves → 3. Librarian Packs → 4. Teacher Issues → 5. Retrieve → 6. Print
⛔ No HOD = No Pack. ⛔ No Pack = No Issue. ⛔ Wrong Class / Wrong Grade / Already Has Title = Blocked. ✅ Any Teacher Can Retrieve Any Book.

📦 Stock — Add / Manage Books

Barcode = Prefix + Number. Example Wordsworth: WHS000001. Renumber fixes gaps after deletes.

🔢 Renumber Books

Tick books below → set Start No. → Renumber Selected. Or Renumber ALL to close gaps.

🏛️ Departments — Create / Edit

Departments control HOD approval. HOD sees ONLY own Department. Teacher Request uses Book's Department. Departments are per-EMIS (per school).

💡 Default Departments: If none exist for your EMIS, we auto-create: Mathematics, English, Afrikaans, Physical Sciences, Life Sciences, Social Sciences, Technology, EMS, Life Orientation. You can edit / delete them here.

📝 Teacher Request

Teacher can ONLY request for OWN class. Pick a book → Qty → SEND TO HOD.

✅ HOD Approval

HOD sees ONLY own Department. Set Approved Qty → APPROVE or REJECT. No HOD = No Package.

📦 Package — Librarian Only

Librarian packs from AVAILABLE only, up to Approved Qty. Packed books move to ISSUE tab.

📤 Teacher Issue

Scan / Pick PACKED barcode → Pick Learner in SAME class → ISSUE. 1 Learner = 1 Title.

🔁 Retrieve — Bring Book Back

ANY Teacher can retrieve ANY book. Scan / Pick ISSUED book → RETRIEVE → Book becomes AVAILABLE again.

🖨️ Print Labels — 3×5 on A4 (15 Labels)

Tick books / learners → PRINT. Book label: WHS000001 + Title. Learner label: 10A001 + Name.
