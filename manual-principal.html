Your Job: Approve, view everything, make sure books come back.

1. Login

Go to login.html → Top must say PRINCIPAL. Set EMIS = Your School.

2. Check Dashboard Daily

Total Books, Available, Packed, Issued, Learners, Requests. If Issued is high at year-end, books are missing. Check 📋 RECORDS → Search learner / barcode to see who has what.

3. Check Subscription

Top banner shows Plan + Expiry. If EXPIRED, contact Super Admin. If DONATION, it shows Donor + School Pays R0.

4. Check Departments

Must have HOD for each Department. No HOD = No Approval = No Pack. Ask Librarian to add missing Departments.

5. Export

EXPORT CSV → Send to District / SGB. You can also Add Stock, Pack, Retrieve, Add Learner like Librarian.
