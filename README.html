🚀 How To Use — Daily Flow

  1. Open index.html → Login with School Code + Password (e.g. WHS / Wordsworth2026).
  2. Issue: Scan Book Barcode → Scan Learner Card → Issue. Forgot card? Search learner by name → Tap → Issue.
  3. Return: Scan Book OR Search Learner → Tap Book → Return. Due Date: 30 Nov.
  4. Print: Open print.html → Print Learner Cards + Book Barcodes (A4 3×5) → Cut + Laminate.
  5. HOD: Teacher requests → HOD approves → Teacher can only issue up to approved number.
  6. Super Admin: Open superadmin.html → Super2026 → Create new school → Set plan → Share code + password with school.
  7. New Lead: Website form → Saves to Sheets + Opens WhatsApp → Appears in Super Admin → Leads → Reply on WhatsApp.
