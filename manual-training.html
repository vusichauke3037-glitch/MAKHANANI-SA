🎓 Training Manual — Makhanani LTSM

Version 1.0 • 23 Nov 2026 • For Trainers Only • Train a school in 1 day

Trainer Golden Rule: Never train by talking only. Trainee must TOUCH the system. If they did not issue + return a book themselves, they are NOT trained.

1. Before Training — Checklist

  • School Name, Code, Password confirmed. Example: WHS / Wordsworth2026. GSH / GeorgeSonto2026.
  • Contact Person: Librarian / HOD / Admin — Name + Phone
  • Departments / HODs list — e.g. Mathematics | Mr. Khumalo | HodMath2026
  • Learner list — Name + ID + Grade + Class (Excel / paper / photo)
  • Book list — Title + Subject + Grade + Copies (Excel / paper / photo)
  • Printed User Manuals — 1 per teacher. 1 pack card paper. 1 laminator demo.
  • Phone charged, Chrome installed, index.html open, Super Admin open
  • Attendance Sheet + Acceptance Form + Pen

2. Opening Script — Say This

Good morning, I am from Xintimani Group, 293 Smit Street, Hillbrow, Johannesburg, 2038. Directors: Vusi Chauke + Hloniphani Success Masia. Today we learn Makhanani LTSM. Makhanani means working together. In 2 hours, you will issue and return books in 2 seconds, with no paper register. No one will be left behind.

3. Training Plan — 2 Hours

ModuleTimeTeach + Practice
1. Why Makhanani15 minLost books cost money. Manual register wastes time. Show overdue list.
2. Login + Roles15 minSchool login, Teacher vs HOD vs Librarian. Each person logs in.
3. Issue30 minScan Book → Scan Learner → Issue. Forgot Card? Search name → Tap → Issue. Each trainee issues 5 books.
4. Return20 minScan Book → Return. Search Learner → Tap Book → Return. Each trainee returns 5 books.
5. Print Centre20 minprint.html → Learner Cards + Book Barcodes A4 3×5 → Cut + Laminate. Print 1 page live.
6. HOD Approvals20 minTeacher requests → HOD approves → Teacher can only issue up to approved number. Role-play: Request 30, Approve 20.
7. Reports15 minHistory, Overdue, Stock, Export CSV. Export History CSV live.
8. Locked + Support10 minWhat 🔒 means. How to upgrade. WhatsApp 078 023 3263. Show locked example.

4. Assessment — Pass = Can Do All 5 Alone

  1. Login alone with School Code + Password
  2. Issue 1 book by scanning
  3. Issue 1 book by searching name (forgot card)
  4. Return 1 book by scanning
  5. Return 1 book by learner search

If trainee fails 1 step, retrain that step only. Do not retrain whole day. Sign Pass / Retrain on Attendance Sheet.

5. After Training — Trainer Must Do

  • Get signed Attendance Sheet + Acceptance signature + Photo of training (no learner faces without school permission)
  • Give school: User Manual PDF + School Code + Password on paper + WhatsApp number 078 023 3263
  • Log in Super Admin: School status = Active, Expiry correct, Depts correct
  • Follow-up: Day 2 WhatsApp check, Day 7 WhatsApp check, Day 30 visit

6. Common Training Mistakes

  • ❌ Talking 2 hours, no practice → ✅ Practice every 10 min
  • ❌ Training only principal → ✅ Train Librarian + HODs + Teachers who will use it daily
  • ❌ Leaving without learner/book list → ✅ Capture list before you leave, or agree date to send it
  • ❌ Promising free forever → ✅ Say: Donated = 12 months free only. Demo = 7 days only. Then choose plan.
